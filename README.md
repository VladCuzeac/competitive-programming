# Competitive Programming Solutions

A curated collection of C++ competitive programming solutions organized by core algorithmic techniques and problem patterns.

## Repository Structure
Solutions are grouped into topic folders (e.g., `Greedy`, `Binary Search`, `DP`, `Graphs`, etc.), with each file corresponding to a single problem.

Each solution file begins with a standardized header block documenting:
- **Problem Name & Platform**
- **Link** 
- **Rating / Difficulty** 
- **Time & Space Complexity**
- **Logic / Approach** 

## Accounts & Practice Workflow
- **Main Contest Account:** Reserved primarily for rated contests to keep official contest history and rating progression clean.(https://codeforces.com/profile/M1le)
- **Practice Account:** Used for ongoing problem solving, upsolving, and daily practice submissions across different topic sheets and difficulty levels.(https://codeforces.com/profile/C_Vlad)
